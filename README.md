## 👨‍💻 Обо мне

Я — **Junior QA Engineer** с уникальным бэкграундом **Product Manager**. За 1+ год в продукте я научился смотреть на качество не только глазами тестировщика, но и глазами пользователя и бизнеса.

**Что отличает меня от типичного Junior QA:**
- 🧠 **Глубокая аналитика**: провёл **30+ глубинных интервью** и **200+ опросов** — умею находить неочевидные сценарии использования и **edge cases**
- 📝 **Навык валидации требований**: написал **20+ user stories** с **acceptance criteria** — знаю, как должна выглядеть качественная документация с обеих сторон
- 🧪 **Опыт тестирования в продакшене**: провёл **15+ юзабилити-сессий**, **4 A/B-теста** с полным циклом, спроектировал **10+ user flows** с проработкой краевых случаев
- 📊 **Data-driven подход**: пишу **SQL-запросы** для анализа тестовых данных, строю дашборды метрик, использую **RICE/MoSCoW** для приоритизации
- 🏗 **Понимание разработки**: работал в **Agile/Scrum** с командами из 5 разработчиков — знаю, как эффективно коммуницировать дефекты и разблокировать задачи

**Мой подход к тестированию:**  
Сначала — понять пользователя и бизнес-логику. Потом — найти слабые места. Затем — задокументировать так, чтобы разработчик понял с первого раза.
