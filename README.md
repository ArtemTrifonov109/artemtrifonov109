# Привет, меня зовут Артём!

---

## 👨‍💻 Обо мне

Я QA Engineer с продуктовым бэкграундом. Стажировка в роли Product Manager научила меня смотреть на качество продукта комплексно: от формулировки требований и acceptance criteria до финальной проверки фич перед релизом.

За время работы над продуктами я участвовал в тестировании UX/UI макетов, валидировал гипотезы через данные, мониторил выполнение задач в спринтах и тесно взаимодействовал с командами разработки и дизайна. Этот опыт дал мне понимание полного цикла разработки ПО и навык выявлять проблемы на ранних этапах.

Сейчас я сфокусирован на развитии в QA. В своём портфолио собрал примеры тестовой документации, баг-репортов, Postman-коллекций для API-тестирования и SQL-скриптов для работы с данными. Работаю с Jira, Confluence, DevTools, Figma и GitHub.

Ищу возможность применить свой аналитический подход и внимание к деталям в команде, где качество продукта стоит на первом месте. Открыт к изучению автоматизации тестирования и новым инструментам.
